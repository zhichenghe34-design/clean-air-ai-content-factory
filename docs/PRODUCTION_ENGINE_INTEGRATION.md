# 生产引擎组合边界

## 目标

时宜 Agent 内容工厂保留可信控制层，MoneyPrinterTurbo v1.3.3 作为已完成工程烟雾验证的独立视频生产引擎。组合原则是先验证、再采用、最小接入；不是把两个仓库整体混合，也不是把第三方能力冒充为本项目原创。

`third_party/moneyprinterturbo/upstream-lock.json` 中的 `source_imported=false` 表示上游源码没有进入 Git 仓库；它不再表示烟雾验证未完成。固定脚本 CLI 与回环 HTTP → `ProductionRunner` 两条工程链均已真实跑通。下一次正式除甲醛闭环采用代理测试审查推进两道门禁，再由用户验收最终成片；该证据仍待完成。

| 验证层 | 状态 | 可证明范围 |
|---|---|---|
| MPT 固定脚本 CLI | 已通过；manifest `D184B944...B87E5E` | 57.31 秒竖屏 H.264/AAC 与字幕生产能力 |
| MPT HTTP → ProductionRunner | 已通过；manifest `F42EA0D7...DB64F` | 46.600 秒适配器、staging 和媒体复验合同 |
| Codex 两道代理测试审查 + 用户最终成片验收 | 尚未执行 | 完成前不能声称正式比赛闭环已经完成 |
| v0.3 最终便携包冷启动 | 尚未完成 | 当前不得提供 v0.3 下载或发布哈希 |

## 两层职责

### 时宜可信控制层

- 生成三个候选并保留用户执行授权；
- 研究证据、严格反证审核、逐条研究审查与最终脚本审查；
- 合规阻断、七次任务硬预算、Provider 白名单与密钥隔离；
- 不可变运行、失败 staging、审批哈希、manifest 与正式产物发布。

### MoneyPrinterTurbo 生产引擎

- 只接收已审批脚本、搜索关键词、9:16 与 45–60 秒规格、素材策略、配音策略和独立 staging；
- 只评估锁文件允许的素材、缓存、任务产物、配音、字幕、视频与非 LLM 视频 API 模块；
- 不调用其 LLM，不重新生成脚本，不接触本项目 Key、预算、证据和审批；
- 失败或超时时只留下当前 staging，不更新上一成功运行。

## 组合门禁

1. 已在隔离环境以固定脚本和自生成本地素材生成真实 9:16 MP4，没有调用上游 LLM、WebUI 或社交上传。
2. 已用 ffprobe、完整解码和抽帧检查验证 57.31 秒、1080×1920、H.264/AAC、字幕连续性及产物可读性。
3. 已完成回环 HTTP → 控制层 staging 联调并再次验证 46.600 秒成片；测试 `approved` 状态不含人工签名，仅证明适配器合同和媒体复验。后续代理测试审查必须以结构化 `agent/test` 身份记录，并明确等待用户最终成片验收。
4. 正式便携包才允许从固定 clean snapshot 把所需上游源码复制到独立 staging；Git 仓库本身继续只保存版本锁、许可证和适配器。
5. 集成优先使用内部 HTTP API；若其生命周期或错误处理不稳定，可以改用本地 CLI/子进程，但上层输入输出合同保持不变。
6. 引擎输出只允许导入成片、音频、字幕、素材来源和脱敏执行摘要。由时宜控制层重新计算哈希、检查 MIME/媒体规格，并在全部通过后原子发布。

## 资源与发布边界

- 上游字体、歌曲和示例素材不进入发布包；字体固定使用 Noto Sans SC，BGM 默认关闭或使用已有明确授权和来源记录的素材。
- 上游 WebUI、LLM 和社交平台上传不进入组合版。
- 当前不承诺智能内容去重；若只具备 URL、文件哈希或缓存键级去重，必须按其真实能力命名。
- v0.3 的目标交付形态是 Windows 本地一键包，不声明公网 SaaS、多人账号、计费或云端托管能力；在最终包冷启动通过前，这仍是交付目标而非已发布事实。
- 发布时保留 MoneyPrinterTurbo 的 MIT 许可证、Harry 版权归属、固定版本/提交以及实际采用与修改说明。

## 回退原则

采用范围从“素材、配音、字幕与渲染”逐级缩减到“素材与渲染”或“只采用素材搜索/缓存”。任何模块不稳定都不应阻挡已验证的时宜生产链；若到冻结期仍无可靠组合闭环，正式提交继续使用 v0.2.0，组合版仅作为未发布预览。

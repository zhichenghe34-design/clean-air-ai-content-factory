# 初赛开题报告

## Part 1：命题前置分析与洞察（199字）

本轮我们从抖音4个搜索页选取6条除甲醛视频，重点观察新房、租房和有孩子家庭三类场景。样片里反复出现的结构，是先用“99%是否可信”这类反常识问题吸引注意，再拆解空间、用量、时长和检测来源；但这6条只是内容样本，没有平台完播率和转化数据，不能代表全行业。结合GB/T 18883-2022与广告法对数据引证的要求，我们认为项目价值不只是提高脚本产能，更在于让功效表达保留来源、适用范围和人工复核入口。

## Part 2：整体解决方案设计（519字）

我们想做的不是一个“输入选题、吐出脚本”的聊天框，而是一套普通运营也能独立使用的内容工厂。用户只需给出选题、受众和素材目录，Flash负责判断下一步，搜索、网页提取、视频分析、审核、配音和合成则交给受控工具。系统先从历史样片中找到可复用的开场、节奏和表达方式，再补充可回溯来源；只有绑定原文摘录的发现才能进入脚本事实层，并一次生成4版脚本。涉及除醛率等功效数字时，必须同时交代用量、空间、时长、初始浓度、检测方法和报告来源；“绝对安全”“彻底去除”“母婴零风险”等无依据说法会被拦截。若联网、模型或资料不足，流程不会硬编结论，而会切换到已审核的安全科普脚本。之后由本地语音工具完成配音，HyperFrames制作动态信息画面，FFmpeg输出9:16成片。运营人员仍可修改脚本、镜头、字幕和音量，并只重跑受影响环节。每次任务都会留下研究来源、脚本版本、审核记录、耗时和最终视频。当前真实联调在208.36秒内产出52.011秒竖屏视频；4个真实DeepSeek候选均未通过硬规则，系统按设计触发安全模板。设计基准流程则有2/4候选进入内部可用集，但两者都不是企业采用率。面向企业落地，我们把“选题到可精修成片不超过2小时”作为首阶段目标。

> 真实DeepSeek联调为0/4并触发安全模板；设计基准为2/4。两者都是内部原型结果，不代表企业真实采用率。

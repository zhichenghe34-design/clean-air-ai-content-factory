# 初赛开题报告（v2）

## Part 1：命题前置分析与洞察

除甲醛短视频常同时涉及功效比例、检测条件、健康风险和入住建议。旧样片说明反常识开场、条件拆解和检测报告讲解适合竖屏表达，但样本没有平台完播率与转化数据，不能外推为行业结论。结合 GB/T 18883-2022 与广告法的数据引证要求，本项目把“证据能回查、人工能否决、失败不覆盖成片”放在产能之前，避免把实验舱结果直接说成家庭效果，也不允许自动系统冒充人工审定。

## Part 2：整体解决方案设计

净界 AI 内容工厂 v2 是仅监听 127.0.0.1 的单机原型。新任务按研究、内容、渲染三段执行，每次只推进到下一道人工作业门禁：用户先逐条批准或拒绝研究 finding，并标记逐字证据或转述；脚本经过本地合规后，仍须用户亲自完成最终放行。无批准证据支持的功效数字、具体测量、医疗因果、健康保证和绝对化表述会被阻断。

每次执行生成独立 run_id 与 staging，验证成功后才原子发布；失败尝试不会更新 current_run_id，也不会覆盖上一成功视频。manifest.json 记录输入、审批、预算和逐文件 SHA-256。相同幂等键重放原结果，不同键并发返回 409；每任务共享最多 7 次 Provider 请求，失败和超时同样计数。DeepSeek 地址固定为官方 HTTPS 白名单，Key 在 Windows 下经当前用户 DPAPI 加密，配置和公开包均扫描敏感字段。

自定义选题限制在赛题领域与 4–80 字。无 Key 时根据真实选题生成安全模板，不再固定输出功效数字。人工改稿会先校验预计朗读时长并撤销旧合规审批；真实配音只有能在 0.75–1.5 倍安全变速内进入 45–60 秒，才允许渲染 1080×1920、H.264/AAC 成片。2026-08-01 的 v2 真实联调由用户亲自完成两次审批，7/7 次 Provider 预算产出 52 秒成片与 13 项脱敏证据包；代理没有代签。旧真实 DeepSeek 运行仅保留为 legacy 对照。

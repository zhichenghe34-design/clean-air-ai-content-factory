# 初赛开题报告

## Part 1：命题前置分析与洞察（231字）

我们在抖音选取了6条除甲醛相关视频，也代入了三类最常见的观看者：刚装修的新房家庭、租客和有孩子的家庭。大家真正担心的并不是“有没有99%”，而是这个数字在多大空间、用了多少产品、测了多久、由谁检测。传播较好的内容往往先用一个反常识问题抓住注意力，再把实验条件拆开讲清楚。现有内容的短板也在这里：会制造焦虑，却很少留下可核查的依据。结合GB/T 18883-2022和广告合规要求，我们判断，项目的价值不只是更快写脚本，而是让每一句功效表述都能回到证据和检测条件。

## Part 2：整体解决方案设计（466字）

我们想做的不是一个“输入选题、吐出脚本”的聊天框，而是一套普通运营也能独立使用的内容工厂。用户只需给出选题、受众和素材目录，Flash负责判断下一步该做什么，搜索、网页提取、视频分析、审核、配音和合成则交给受控工具完成。系统会先从历史样片中找到可复用的开场、叙事节奏和表达方式，再补充可信来源，生成4版脚本。涉及除醛率等功效数字时，必须同时交代用量、空间、时长、初始浓度、检测方法和报告来源；“绝对安全”“彻底去除”“母婴零风险”等无依据说法会被直接拦截。若联网、模型或资料不足，流程不会硬编结论，而会切换到已审核的安全科普脚本。之后由本地语音工具完成配音，HyperFrames制作动态信息画面，FFmpeg输出9:16成片。运营人员仍可修改脚本、镜头、字幕和音量，并只重跑受影响的环节。每次任务都会留下研究来源、脚本版本、审核记录、耗时和最终视频，方便复盘。当前真实联调已在约3分28秒内产出一条52秒竖屏视频；面向企业落地，我们把“选题到可精修成片不超过2小时”作为首阶段目标，并用真实采用率、合规命中率和多账号产能继续验证。

> “4版脚本中至少2版仅需小改”是项目内部代理指标，不代表企业真实采用率。

# 安全与合规边界

## Agent权限

控制台区分“发现项目”和“执行项目”。Agent只能选择受信能力包ID并调用代码中登记的适配器，不能搜索安装源、提交任意下载地址、拼装系统命令或执行未知仓库README。

## 健康与广告表述

系统自动标记以下内容并要求人工确认：

- 绝对化表述，如“绝对安全”“完全去除”“零风险”。
- 没有品牌事实库支持的具体功效、检测结论和健康承诺。
- 只出现百分比、不说明测量对象、空间、时间、初始浓度、方法和来源的结论。
- 把实验舱条件直接外推到真实家庭整屋场景的表述。

系统负责预警和保存证据缺口，不把文本审核包装成法律结论。品牌、科学与广告合规最终由人工负责。

## 数据与密钥

- API Key仅从环境变量或当前进程读取，不进入任务产物、代码、截图和日志。
- 本地素材默认不上传。
- `runtime/`、`.env`、语音参考和临时文件均被Git忽略。
- 示例数据只保留结构化脚本与运行结果，不包含个人信息。

## 能力安装

自动安装默认关闭。未来开放的每个能力包必须固定原始地址、镜像、版本、SHA-256、许可证、适配硬件和回滚方案，并先在隔离环境验证。

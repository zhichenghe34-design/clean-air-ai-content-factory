# v2 安全与合规边界

## 本地服务

- 只允许绑定 `127.0.0.1`，不监听局域网或公网地址。
- 所有 POST/PATCH 要求当前会话 Cookie、CSRF、JSON Content-Type 与实际端口同源 Origin。
- 统一返回 JSON 错误；非法任务 ID、Plan、Production Input 和路径不会断开连接。

## Provider 与 Key

- 正式 Provider 只允许 `https://api.deepseek.com` 与 `/v1`，拒绝凭据、查询串、片段、非标准端口和越界重定向。
- localhost 只用于显式测试开关。
- Windows 持久化 Key 使用当前用户 DPAPI，加密后回读验证再原子替换；旧明文迁移失败时不再读取该文件并显示告警。
- 非 Windows 不落盘，只支持环境变量或当前进程会话。
- Provider 错误、解析器配置、任务文件与公开包都执行敏感字段脱敏/扫描。

## 研究与健康内容

- 模型只能整理受控工具实际返回的来源；网页正文是不可信数据，不能改变系统指令。
- 自动研究只标记 `auto_review_status`，不能声称人工已核验。
- 每条可入脚本 finding 都必须由用户批准或拒绝，并声明逐字或转述证据。
- 医疗因果、健康保证、绝对化表达、无批准证据支持的功效或测量数字一律阻断。
- 自动通过不等于品牌、科学或广告合规结论，最终脚本仍须人工放行。

## 外部与媒体工具

- Agent 不能生成安装地址、拼接任意命令或执行未知仓库 README。
- 一站式解析器只接收白名单配置；敏感字段不会复制到 job 目录。
- HyperFrames 和 Node 依赖由 `package-lock.json` 锁定，运行时禁止自动下载。
- 原始素材不覆盖，失败 staging 不公开，失败运行不替换上一成功成片。

## 发布扫描

公开证据包必须检查 Key、Cookie、Authorization、本机绝对路径、个人信息和原始配置；复算全部 SHA-256，并用 FFprobe 验证 45-60 秒、1080x1920、H.264/AAC 与字幕连续性。

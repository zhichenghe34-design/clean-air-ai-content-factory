# 通用 Agent 内核 v3

## 当前边界

这一版先完成可运行的通用结构，不把当前页面当作最终 UI。下一轮视觉与交互重设计会增加侧边常驻输入框，并把“打断当前阶段”与“不中断、在下一安全边界应用”做成显式选择。当前 API 已接受 `mode: interrupt | defer`，但 `interrupt` 只被安全记录，尚不会强行终止正在等待返回的外部请求；默认行为是 `defer`。

原净界除甲醛项目没有被改写成通用项目。它作为 `legacy-clean-air-v2` 行业能力包和历史比赛证据继续保留，旧成片、审批和哈希不能证明新行业已经完成真实联调。

v2 的 13 个本地工具能力包是冻结目录事实；v3 的行业能力包只保存声明式约束，不能与前者混为同一数量或作为联调证据。正式发布主链使用本地确定性安全能力包，动态生成与启动反证只保留为实验路径。视频生产默认采用本地纯动画：固定 HyperFrames 0.7.86 与可信动画注册表负责确定性镜头和渲染，MoneyPrinterTurbo 保留为实拍支线；这两种生产引擎也不能与行业能力包混为一谈。当前 295 项 Python 测试由 `unittest discover` 动态发现，这个当前数不回写 v2 PDF 或历史比赛说明。

## 项目启动

1. 用户提交 4—200 字内容目标。
2. 正式路径根据真实目标构建本地确定性安全能力包并计算规范化 SHA-256；命令、脚本、密钥和任意 URL 不能进入能力包。
3. 有 Key 且预任务额度可用时，Agent 只请求一次三个候选；没有 Key、Provider 失败或额度耗尽时，系统根据同一目标生成三个本地安全候选，不借用净界文案。
4. 候选只代表研究方向，不能把未经研究的内容写成事实；选中后仍进入严格反证、研究逐项审查和最终脚本审查。正式模式由用户确认；受控测试模式由 Codex 通过浏览器检查并操作，最终成片再交用户验收。
5. 动态行业能力包生成与启动阶段反证协议保留为实验路径，通过 `SHIYI_EXPERIMENTAL_DYNAMIC_TOPICS=1` 启用，不阻断正式发布主链。

实验路径的项目启动结构失败时，API 只返回本地固定的 `bootstrap_failure_kind` 和经过二次严格验证的四字段 shape 诊断；未知字段原名、模型值、异常正文和 HTTP 正文不会进入响应或内部 capture。正式路径明确记录启动与启动反证均为 `not_run`，不会把跳过伪装成通过。

能力包只是生产约束，不是研究证据。企业资料、产品功效、价格、业绩、认证、排名、证言、医学因果等内容仍必须经过公开来源、严格反证审核和当前任务固定的阶段审查；代理测试审查不得冒充人审或品牌背书。

## 任务执行

新任务继续使用 v2 的状态机、两道哈希阶段门禁、7 次任务硬预算、同任务锁、幂等、失败运行隔离和成功 manifest。任务输入额外固定：

- 能力包 `id`、版本和 SHA-256；
- 该次任务实际使用的纠错规则及规则 ID；
- 能力包与规则集合的 manifest 哈希。

研究、脚本、修订、合规和画面计划都读取同一个能力包。只有 `legacy-clean-air-v2` 可以使用旧的六项检测条件、甲醛精确证据和净界视觉语义；普通能力包若混入这些内容，本地合规会阻断。

## 纠错、记忆与 Skill

`POST /api/agent/corrections` 把工作人员原话追加写入 `corrections.jsonl`，再生成声明式规则。规则只能增加限制，不能覆盖证据、安全、预算或人工门禁。

作用域分为：

- `task`：只对当前任务生效；
- `project`：对同一行业能力包生效；
- `workspace`：对所有项目生效，必须由明确的全局措辞或显式作用域产生。

纠错不会自动通过任务门禁。非运行状态会立即重算下游内容状态，并保留匹配当前研究哈希的研究审查；运行中纠错先持久化，在下一次安全阶段边界同步。上一份成功成片和 manifest 始终保留。

同一条非 task 规则只有在三个不同成功任务中被实际采用后，才会生成可复用 Skill。Skill 编译完全在本地完成，发布前使用独立 staging 验证，只允许：

- `SKILL.md`
- `skill.json`
- `examples.json`
- `tests.json`

Skill 不包含命令、脚本、URL、Cookie、Token、Key 或本机路径。重复记同一个任务不能凑够三次。

## 当前接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/agent/topics` | 正式路径使用确定性安全能力包并返回三个候选 |
| GET | `/api/capability-packs` | 返回能力包脱敏摘要，不返回目标或证据规则全文 |
| POST | `/api/agent/corrections` | 记录纠错并应用或排队到安全边界 |
| GET | `/api/learning` | 查看纠错事件与已经晋升的 Skills |

所有写接口继续受本机会话 Cookie、CSRF、JSON Content-Type 与当前端口同源 Origin 保护。

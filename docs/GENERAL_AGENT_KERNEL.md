# 通用 Agent 内核 v3

## 当前边界

这一版先完成可运行的通用结构，不把当前页面当作最终 UI。下一轮视觉与交互重设计会增加侧边常驻输入框，并把“打断当前阶段”与“不中断、在下一安全边界应用”做成显式选择。当前 API 已接受 `mode: interrupt | defer`，但 `interrupt` 只被安全记录，尚不会强行终止正在等待返回的外部请求；默认行为是 `defer`。

原净界除甲醛项目没有被改写成通用项目。它作为 `legacy-clean-air-v2` 行业能力包和历史比赛证据继续保留，旧成片、审批和哈希不能证明新行业已经完成真实联调。

v2 的 13 个本地工具能力包是冻结目录事实；v3 的动态行业能力包按真实任务生成，只保存声明式约束，不能与前者混为同一数量或作为联调证据。当前 154 项 Python 测试由 `unittest discover` 动态发现；这个当前数不回写 v2 PDF 或历史比赛说明。

## 项目启动

1. 用户提交 4—200 字内容目标。
2. 启动 Agent 现场识别行业、受众、平台、内容目的、语气、证据要求、禁用主张和视觉方向。
3. 系统把模型输出收进字段白名单，计算规范化 SHA-256；命令、脚本、密钥、任意 URL 和未知字段不能进入能力包。
4. 独立反证 Agent 以“所有内容默认虚假”为前提，只能否决候选或缩小使用范围，不能补写事实。
5. 通过的限制进入能力包快照；能力包以 `<id>/<sha256>.json` 原子发布，历史版本不覆盖。
6. Agent 返回三个候选。没有 Key、Provider 失败或预算耗尽时，系统根据同一个真实目标生成本地通用候选，不借用净界文案。

能力包只是生产约束，不是研究证据。企业资料、产品功效、价格、业绩、认证、排名、证言、医学因果等内容仍必须经过公开来源、严格反证审核和人工审批。

## 任务执行

新任务继续使用 v2 的状态机、两道人审、7 次任务硬预算、同任务锁、幂等、失败运行隔离和成功 manifest。任务输入额外固定：

- 能力包 `id`、版本和 SHA-256；
- 该次任务实际使用的纠错规则及规则 ID；
- 能力包与规则集合的 manifest 哈希。

研究、脚本、修订、合规和画面计划都读取同一个能力包。只有 `legacy-clean-air-v2` 可以使用旧的六项检测条件、甲醛精确证据和净界视觉语义；普通能力包若混入这些内容，本地合规会阻断。

## 纠错、记忆与 Skill

`POST /api/agent/corrections` 把工作人员原话追加写入 `corrections.jsonl`，再生成声明式规则。规则只能增加限制，不能覆盖证据、安全、预算或人工门禁。

作用域分为：

- `task`：只对当前任务生效；
- `project`：对同一行业能力包生效；
- `workspace`：对所有项目生效，必须由明确的全局措辞或显式作用域产生。

纠错不会自动批准任务。非运行状态会立即重算下游内容状态，并保留匹配当前研究哈希的研究审批；运行中纠错先持久化，在下一次安全阶段边界同步。上一份成功成片和 manifest 始终保留。

同一条非 task 规则只有在三个不同成功任务中被实际采用后，才会生成可复用 Skill。Skill 编译完全在本地完成，发布前使用独立 staging 验证，只允许：

- `SKILL.md`
- `skill.json`
- `examples.json`
- `tests.json`

Skill 不包含命令、脚本、URL、Cookie、Token、Key 或本机路径。重复记同一个任务不能凑够三次。

## 当前接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/agent/topics` | 生成能力包、反证审核并返回三个候选 |
| GET | `/api/capability-packs` | 返回能力包脱敏摘要，不返回目标或证据规则全文 |
| POST | `/api/agent/corrections` | 记录纠错并应用或排队到安全边界 |
| GET | `/api/learning` | 查看纠错事件与已经晋升的 Skills |

所有写接口继续受本机会话 Cookie、CSRF、JSON Content-Type 与当前端口同源 Origin 保护。

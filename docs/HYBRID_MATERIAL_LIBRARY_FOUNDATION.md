# 素材库 + 代码动画混剪底座

## 当前状态

- 产品已保留 `hybrid` 生产模式和独立的素材输入边界。
- `hybrid` 现在仍然 fail closed：没有完成内容匹配、时间线编排和终端输出验收前，不会伪装成可用功能。
- 本轮只收口纯代码动画样品，不将一百段素材自动混剪偷偷扩展进来。

## 预留合同

1. 每段素材都以不可变 SHA-256 识别，原文件不覆盖。
2. 文件名可作为第一层内容标签，但不直接当作画面事实；后续仍要生成结构化目录。
3. 目录最少包含：`asset_id`、语义标签、时长、分辨率、帧率、声音状态、授权来源和可用范围。
4. 脚本先拆成可二次核对的句子/镜头意图，再进行素材候选检索；没有匹配就走代码信息图，不伪造“相关画面”。
5. 同一素材的连续复用、无意义循环、装饰特效替代内容和裁切主体均为拒绝项。
6. 代码动画只用于表达数字、条件、步骤、时间线、比较和证据关系；不覆盖真实素材中应由人看的主体。
7. 最终时间线必须记录每个镜头选中理由、来源和替代候选，以便人工抽查与重建。

## 启用门禁

后续只有在“100 段×3 秒”类似的授权素材库完成目录化后，才启动实现。最小验收是：固定脚本下的选片可复现、语义匹配可解释、相邻镜头不重复、主体不裁切、音频不冲突、所有素材授权可追溯。

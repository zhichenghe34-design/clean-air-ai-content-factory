# Agent 工作台发布摘要 - v2

命题：AI 驱动的短视频内容工厂，面向除甲醛品类的 AIGC 脚本与视频内容生成。

v2 将原单机样机加固为 Agent 优先、三段生产、两道人工作业门禁的可审计流程。首页采用三选一：Agent 每轮给出三个经领域与安全筛选的选题角度；用户选中一个即完成执行授权，此后系统自动推进，只在研究证据和最终脚本两处人工暂停。详细页仍可逐项批准、拒绝或退回 finding。每次执行有独立 run、预算和 SHA-256 manifest，失败重跑不会覆盖上一成功成片。

| 项目 | v2 结果 |
|---|---|
| 默认地址 | `127.0.0.1:8765`，端口占用时仅在 loopback 顺延 |
| 能力目录 | 13 个本地工具能力包（v2 冻结目录；不等同于 v3 动态行业能力包） |
| Provider | DeepSeek 官方 HTTPS 白名单；测试 loopback 单独开关 |
| 密钥 | Windows DPAPI；非 Windows 环境变量/会话 |
| 模型硬预算 | 单任务最多 7 次 attempted |
| 人工门禁 | 主流程两处单按钮确认；详细页保留逐 finding 审定与退回 |
| 测试 | v2 历史基线为 74 项 Python 测试；另有 JS、浏览器、依赖与媒体检查 |
| 视频范围 | 原三支视频未返工；v2 真实联调另生成一支 52 秒审计成片 |

2026-08-01 的 v2 真实 DeepSeek 联调实际使用 7/7 次硬预算，严格反证审核在“所有内容默认虚假”的前提下逐条核对原文摘录、可信来源、数字、范围和模型否决结果；3 条 finding 通过。用户亲自完成研究逐项审定与最终合规放行后，系统产出 52 秒、1080×1920、H.264/AAC 成片。公开包含 13 项文件并通过哈希、字幕、媒体与秘密扫描。Agent 工作台的流程演示使用固定 mock，不调用 Provider、不创建真实任务，也不冒充真实联调。2026-07-18 的旧联调继续保留为 legacy 对照。

本项目不把自动审核包装成法律结论，也不把公开视频或通用标准当成具体产品功效证明。

# 初赛交付摘要

## 命题

AI驱动的短视频内容工厂：面向除甲醛品类的AIGC脚本与视频内容生成。

## 我们怎么回答这个命题

我们不想只做一个会写脚本的聊天框。用户给出选题、受众和素材目录后，Flash负责判断下一步该做什么，搜索、网页提取、样片分析、审核、配音和视频合成则由已经登记的工具完成。系统先从6条代表性视频中学习开场和叙事方式，再补充可信来源、生成4版脚本；遇到功效数字时，必须补齐检测条件和报告来源。资料不足时不硬编结论，而是切换到已审核的安全科普脚本。

脚本通过后，本地语音工具、HyperFrames和FFmpeg会继续完成动态画面、字幕、配音和竖屏成片。人工仍能修改脚本、镜头、字幕和音量，并只重跑受影响的环节。研究来源、脚本版本、审核结果、运动方案和最终视频都会保存下来，方便复核。
